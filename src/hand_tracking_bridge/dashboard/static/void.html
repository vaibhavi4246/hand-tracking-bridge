Infinite Void

Real-time hand tracking pipeline that turns your hands into instruments — control 3D objects, synthesize music, and interact with digital space, all without touching a single button.

How it works

Your webcam feeds into a MediaPipe hand landmarker that extracts 21 3D keypoints per hand at ~30 FPS. A gesture engine computes pinch, openness, palm orientation, finger flexion, and velocity — all smoothed with a One Euro filter to eliminate jitter. The pipeline streams this data via WebSocket into your browser in real time.

Webcam → MediaPipe Tasks → Gesture Engine → One Euro Filter ↓ WebSocket /ws → Browser ↙ ↘ Void (Three.js) Studio (Web Audio)
